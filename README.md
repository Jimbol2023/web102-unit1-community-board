# Web Development Project 1 - AI & Cybersecurity Learning Hub

Submitted by: **Olabode Jimoh**

This web app is a React-based community board that showcases valuable learning resources for students interested in Artificial Intelligence and Cybersecurity. The application features 10 themed resource cards, each displaying an icon, title, description, and external "Learn More" link.

Time spent: **4** hours spent in total

## Required Features

The following **required** functionality is completed:

* [x] The app has a cohesive, unique theme for events or resources relevant to a specific community
* [x] Header/title describing the theme is displayed
* [x] At least 10 unique resources are displayed in a responsive card format
* [x] There are at least 10 cards displayed for 10 different resources
* [x] The cards are displayed in an organized format (grid layout)
* [x] Each card includes information about the resource

## Optional Features

The following **optional** features are implemented:

* [x] Buttons or links to related resources are on each card component
* [x] All cards have buttons or links in addition to text
* [x] The site is responsive for both desktop and mobile formats
* [ ] Web app is shown in a mobile format
* [x] Video walkthrough

## Additional Features

The following **additional** features are implemented:

* [x] Hover effects on cards
* [x] Reusable React Card component
* [x] Props used to pass data into components
* [x] Custom AI & Cybersecurity theme
* [x] GitHub repository deployment and version control
