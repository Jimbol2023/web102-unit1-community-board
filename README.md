# WEB102 Unit 1 Project - Community Board

Submitted by: Moses

This web app is a Community Board project created for WEB102. The application displays useful resources related to Artificial Intelligence and Cybersecurity.

Time spent: 2 hours

## Required Features

The following required functionality is completed:

- [x] The app has a cohesive, unique theme for resources relevant to a specific community
- [x] A header/title describing the theme is displayed
- [x] At least 10 unique resources are displayed in a responsive card format
- [x] There are at least 10 cards displayed for 10 different resources
- [x] The cards are displayed in an organized layout
- [x] Each card includes information about the resource

## Stretch Features

The following stretch functionality is completed:

- [x] Buttons or links to related resources are on each card component
- [x] The site is responsive for desktop and mobile formats
- [x] Cards include hover effects

## Notes

This project was built using React and Vite. It uses a reusable Card component and passes data through props.
